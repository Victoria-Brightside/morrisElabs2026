# Laboratorio: Crear un Asistente Serverless en Bedrock

##

En este laboratorio se le proporcionará un entorno en el cual ... Su objetivo es construir un asistente conversacional serverless de -tema- utilizando Amazon Bedrock: creará una Knowledge Base conectada a S3 Vectors que indexará los documentos de -tema-, configurará un Guardrail de seguridad, desplegará una función Lambda que orquesta la búsqueda de contexto en la Knowledge Base y la generación de respuestas con el modelo Amazon Nova Lite, y expondrá todo a través de Amazon API Gateway conectado a una página web estática alojada en S3.
